## 📖 How to Read These Files

### In Terminal
```bash
# View a file
cat USER_MANUAL.md

# Page through (recommended)
less USER_MANUAL.md
# Use: Space=next, b=back, /=search, q=quit

# Search for topic
grep "vector" USER_MANUAL.md

# View specific section
head -100 USER_MANUAL.md
```

### Print for Reference
```bash
# Print reference card
lpr QUICK_REFERENCE.md

# Print specific file
lpr USER_MANUAL.md
```

### Copy for Offline
```bash
# Copy single file
cp USER_MANUAL.md ~/Documents/

# Copy entire docs folder
cp -r ./* ~/Documents/Deriva_Docs/
```
